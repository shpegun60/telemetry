Critic comparison draft - capability matrix sources (2026-09-25)
===============================================================

Evidence tags used by the research: V = confirmed on a fetched official page; S = seen only
in an official-site search snippet; I = inference from confirmed facts; M = from memory,
not checked on the web. Cells for this library come from the code, the READMEs and the
trial in this directory (Notes.txt), not from the web.

Cell codes: Y yes, P partial, N no. "meta" = units / limits / defaults / enums / flags.
